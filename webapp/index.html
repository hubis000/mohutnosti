This tool gives a first-order estimate only. The horizontal tail arm and mean aerodynamic chord (MAC) are computed from the drawn wing/tail outlines by slicing them span-wise, which is a good approximation for a clean planform but degrades on a heavily broken or non-planar (e.g. cranked, winglet-heavy) shape. The vertical tail arm still relies on the manually marked wing reference station. Always verify results against a proper 3-view drawing or the manufacturer's geometry before using them for design decisions.

Side profile centroid (weighted) idle

Trace any set of side-profile shapes — fuselage side area, wing planform as seen from the side (dihedral projection), horizontal stabiliser side area, vertical tail, and so on — and give each a weight. The combined centroid is the weighted average of each shape's own centroid, weighted by weight × area. Weight defaults to 1 (equal, unweighted contribution by true area); lower or raise it to reflect a surface's effectiveness.

Station is measured from the nose along the nose→tail axis; offset is the perpendicular distance from that axis (sign is arbitrary — one side positive, the other negative — just keep it consistent when comparing shapes).

Inputs used

Longitudinal stability — horizontal tail volume VHT

—

VHT = (SHT × LHT) / (SW × MAC), using the wing's mean aerodynamic chord (MAC) and the distance between the wing's and horizontal tail's own quarter-chord stations.

Lateral stability — vertical tail volume VVT

—

VVT = (SVT × LVT) / (SW × b)

Typical reference ranges (general aviation / UAV, for sanity-checking only)

VHT ≈ 0.4–0.7  ·  VVT ≈ 0.02–0.06. These vary a lot by configuration — treat as a rough sanity check, not a target.

Export

Exports every drawn shape (top-view wing/horizontal tail, side-view vertical tail and weighted surfaces), each shape's own centroid, the wing MAC quarter-chord point, and a text summary of SW, MAC, SHT, SVT, LHT, LVT, VHT, VVT and the combined weighted side centroid — as a DXF file in metres, so it can be checked against a 3-view drawing in CAD.
