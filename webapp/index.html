This tool gives a first-order estimate only. It approximates the tail moment arm using shape centroids and the wing mean chord as (wing area / span), not the true quarter-chord MAC arm. Always verify results against a proper 3-view drawing or the manufacturer's geometry before using them for design decisions.

Tip: the wing reference station is where the wing's quarter-chord crosses the fuselage — approximate it as roughly the middle of the wing root chord, seen or projected from the side.

Inputs used

Horizontal tail volume coefficient

—

VHT = (SHT × LHT) / (SW × c̄), where c̄ = SW / b (mean geometric chord)

Vertical tail volume coefficient

—

VVT = (SVT × LVT) / (SW × b)

Typical reference ranges (general aviation / UAV, for sanity-checking only)

VHT ≈ 0.4–0.7  ·  VVT ≈ 0.02–0.06. These vary a lot by configuration — treat as a rough sanity check, not a target.
